# 从“看起来不对”走到有效修改

## 主次顺序决定先改哪一层

先回答画面最主要的失败是什么：看不懂主体、材料认错、运动因果不成立，还是局部瑕疵。前者没有解决，不把时间耗在火花、光斑和高清纹理上。无需机械打总分；主体失败不能被其他项目高分抵消。

“丰富度”来自被组织的差异：一块连续主物质中有大小不同、密度不同、速度不同的区域。每个区域都同样亮、同样细、同样快，即使复杂也会显得平。

## 常见观感与优先动作

| 观感 | 先区分 | 推荐动作与通过信号 |
|---|---|---|
| 简陋、干燥、像占位效果 | 缺的是主体、中尺度物质，还是小细节？ | 先给主体明确体积与成片的材料变化；把几个孤立亮条组织为连续流域。正常镜头先读到物质，而非数清发射器零件。 |
| 透明贴纸 | 是低覆盖/混合错误，还是没有厚薄与遮挡关系？ | 对亮暗背景检查致密区与边缘；先恢复中段覆盖和前后关系，再保留柔边。不能全部加 alpha，也不能仅加 RGB。技术根因交给实际 shader 检查。 |
| 霓虹圆环、机械转盘 | 是否等宽、等亮、同速，纹理和形体一起刚性旋转？ | 自然热流可用宽度/疏密变化、局部差速和短折流打破均匀性；保留整体方向。法阵或科幻装置若本就要求精确环，不硬塞随机噪声。 |
| 火墙、甜甜圈、塑料壳 | 是否把三维感等同闭合圆筒或高大环壁？ | 根据材料选局部翻卷、开放褶面、体积团与缝隙，保持高度不均和主体连接。真实石壳则可保留硬轮廓；不能一律柔化所有效果。 |
| 通心粉、贝壳、面条状热流 | 截面、封口、宽度或 UV 条纹是否暴露刚性零件？ | 先替换不合适的几何表达；热流可用非平面开放短幅与宽边渐隐，避免规则封闭截面。先做一个样本，不先扩展六种变体。 |
| 很亮却没力量 | 是否全程高亮、峰值太宽，或各层各自依次亮起？ | 保持已定时序，强化事件前后面积/速度/形变反差；让同一次释放推动主体和次级层。能读到连续物质受压再释放，而非播放灯光清单。 |
| 爆炸过碎 | 主物质是否本已断裂，还是粒子把大形拆散？ | 先查源场与目标表示，保住连续主冲击；细碎只当次级。连通性指标可定位问题，但壳状单体也可能没有体积感。 |
| 爆炸太软、像棉花 | 是否过度平滑、扩张匀速、缺少剪切方向？ | 保护主形，保留有方向的大折面/密度梯度和短促释放；不要只叠高频噪声。峰值果断，余势有惯性。 |
| 色调不统一 | 是色相家族不同，还是照明、覆盖、发光角色不同？ | 在同场景实际输出中比亮部/中段/薄缘。先调关系而非拉齐平均值；保留材质各自的亮暗与饱和度差异。 |
| 发灰、脏泥感 | 是否为配色做了过强去饱和或把明暗都压到中间？ | 保留少量高温亮丝和有色主体，低覆盖区更克制。不要把“物理可信”误解为所有颜色都低饱和。 |
| 有粒子却无立体感 | 单团太小、只在一平面、轨迹被主体完全吞没，还是取样过暗？ | 用同机位开/关对照区分原因。少量有合理高度和尺度的主辅助层胜过大量微点；普通侧视应看到轮廓或遮挡的增益。 |
| 零件拼接感 | 各层是否在形状、速度、颜色或出生时刻上互不相关？ | 将材质来源、运动方向与阶段关系统一；必要时删层。过渡不是简单同时淡入淡出，应有物质延续或明确事件因果。 |
| 背景扭曲像水波或光圈 | 只是发光轮廓，还是背景真正偏移且方向正确？ | 用清晰背景线判断位移与范围传播；在物质流和扭曲之间形成同一引力/冲击意图。不能只凭亮环承诺透镜效果。 |

## 颜色统一与轮廓控制

对比应包含保留层，不要孤立评价新图。新盘单独好看、和旧弧合起来像两个色温系统，仍未完成任务。反过来，两个材质的平均颜色相同，也可能一个是热白发光、另一个是灰褐泥。

先确定亮部、主体、稀薄边缘各自的角色。热物质可以亮部更浅、主体有饱和度、薄缘更克制；寒冰、毒雾、魔法等不必沿用此配方。调色、覆盖率和发光分开判断；“源 RGB 没变”不自动意味着最终亮度没变。

软边不是模糊整张图：主体内部保持结构，轮廓的密度和覆盖率逐渐消失。高频细丝应在近景可读，拉远能合成为有方向的中尺度流，而非变成脏噪点。合法的硬边也要保留，例如岩块断面、法阵线条、黑洞核心边界。

## 运动的最小因果说明

对主要运动用一句话说明原因与结果，例如“外侧物质先被拉起，向内加速时被剪切拉长，接近核心后消失”。以此核对位置、速度、长度、密度与寿命是否彼此支持。

- 吸入不等于匀速绕圈；快速不等于所有层一起加速。
- 颤抖不等于周期涨缩；细小高频扰动与主体缓慢膨胀可以并存，但以用户最终要求为准。
- 三维爆炸不等于把平面图放大；固定机位可接受的光学近似，在环绕镜头下可能露馅。
- 强冲击不等于无限缩短所有时间：主冲击可以瞬时，碎屑、卷流和热衰减需要自己的响应。
- 源序列无缝不代表整套独立粒子同时无缝；检查真实播放区间，不拿 GIF 循环跳变误判源动画。

## 决定保留、返修还是删掉

**保留**：目标镜头里有明确贡献，问题只在不相关的极端视角或无意义放大中出现。

**返修**：贡献方向正确但材料/尺度/运动不成立；保留其已经有效的部分，只改决定性缺陷。

**删除或换表达**：辅助层与主体竞争、只能用解释才能看懂，或调了颜色仍像错误材料。用户明确要求该职责时，换一种实现完成职责，不悄悄删掉要求本身。

同一条修补路线反复失败时回到假设：是在修形态、材质，还是诊断器本身？不要把失败层复杂化成另一套系统。已经得到正确方向后，完成其余变体与最终检查，不为取悦评分反复开新方向。
